# shwn.design sound palette

Source inspected: <https://shwn.design/projects> on 2026-09-28.

The site generates these sounds at runtime with the Web Audio API. It does not
download audio samples. `presets.json` preserves the oscillator, filtered noise,
envelope, pitch glide, gain, and feedback delay settings found in the site's
public JavaScript bundle. The MP3 files in this directory are deterministic
previews rendered from those settings for easy auditioning.

## Automatic interaction mapping

| Interaction | Sound |
| --- | --- |
| Pointer hover | `chime` |
| Pointer down | `press` |
| Pointer up | `release` |
| Toggle click | `toggle` |
| Default button click | `pulse` |
| Navigation link | `arrival` |
| Close, dismiss, cancel, back, pause, or stop | `tick` |
| Next or previous | `page` |
| Play | `ready` |
| Search | `scan` |
| Send, submit, or request | `success` |
| Open dialog | `bloom` |

The complete palette also contains `sparkle`, `droplet`, `whisper`, `loading`,
and `error`. Elements can select any preset explicitly through the site's
`data-sound` attribute.

The noise layers are randomly generated by the original implementation, so
each live playback can differ slightly. The MP3 previews use a fixed random
seed so they remain stable between builds.
